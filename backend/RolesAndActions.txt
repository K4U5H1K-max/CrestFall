1. Order Management Agent
Maintains order priorities, tracks order health, and coordinates the fulfilment process. It needs to know whether an order is waiting for picking, packing, dispatch, delivery, or return processing.

2. Picker Agent
Picks one item at a time, not an entire order in one operation. It selects an item, travels to its location, retrieves it, and transfers it to the packing workflow. An order containing five items therefore requires five successful item-picking operations.

3. Packer Agent
Receives picked items, associates each item with its correct order, verifies completeness, and packs the order as one entity. The packed order becomes a single unit for dispatch and delivery.

4. Inventory Agent
Maintains item availability and inventory records. It can identify stock shortages, track returned inventory, and determine whether returned items can be restocked once inspected.

5. Dispatch Agent
Coordinates the handover of packed orders from the fulfilment center to delivery. It manages dispatch readiness and potential congestion between packing and outbound transport.

6. Delivery Agent
Transports a packed order from the center to the delivery location. It also handles failed deliveries, customer rejections, and the physical return of orders to the center.

"request_reassignment" = "Requests reassignment of an order or task when its current allocation is unsuitable or progress has stalled."
"validate_return_request" = "Checks whether a customer's return request is eligible under the return policy and initiates the return workflow if approved."
"monitor_order_status" = "Observes order progress, health, cancellation outcomes, and return status through the simulation environment."

2. Picker Agent
"select_picking_task" = "Selects an eligible order or item-picking task from the available workload."

"move_to_location" = "Travels to the selected storage location, consuming simulation time."
"pick_item" = "Picks exactly one physical unit of the required product for an order."
"handover_item" = "Transfers a picked unit to the packing workflow and records the change in custody."
"report_blockage" = "Reports obstacles such as missing stock, inaccessible locations, or item mismatches."
"wait" = "Waits when no feasible picking task is available or the agent cannot start another operation."

3. Packer Agent

"receive_item" = "Accepts a physical unit handed over by the Picker."
"associate_item_with_order" = "Associates a received unit with the correct order and order line."
"verify_order_contents" = "Checks that all required products and quantities have been received and are valid for packing."
